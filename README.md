## 1. Leave Management System
**Platform:** OutSystems Reactive Web App  
**Date:** March 2026  
**Project Link:** [https://github.com/rozee11/Rihal-Codestacker26.git]

- Developed a role-based leave management system with distinct portals for Employees, Managers, and Admins to handle the complete request lifecycle.

- Implemented admin dashboards with real-time charts and summaries for monitoring requests by status and leave type.
- Enabled full request lifecycle management, from draft creation and submission to approval or rejection through secure role-based workflows.
