## 1. DailyPress – Newspaper Management System
**Platform:** OutSystems Reactive Web App  
**Date:** 2026  
**Project Link:** [GitHub Repository](https://github.com/rozee11/Rihal-Codestacker26.git)
- Developed a web-based Newspaper Management System with an Admin Panel and a Public Website for local and global news.
- Designed a relational database with Posts, Categories, Tags, Comments, and PostTag entities, including one-to-many and many-to-many relationships.
- Implemented CRUD operations, role-based access, search, filters, pagination, and form validation.
- Built an admin dashboard to manage articles, categories, tags, and comments, including comment approval and rejection.
- Integrated external news APIs to display global news and worked with email integration.
- Designed a responsive and user-friendly interface using OutSystems and custom CSS.

## 2. Leave Management System
**Platform:** OutSystems Reactive Web App  
**Date:** March 2026  
**Project Link:** [GitHub Repository](https://github.com/rozee11/DailyPress-OutSystems-Project.git)

- Developed a role-based leave management system with distinct portals for Employees, Managers, and Admins to handle the complete request lifecycle.
- Designed structured entities for leave types and requests with validations including date restrictions, weekend exclusions, and edit/delete permissions based on request status.
- Implemented admin dashboards with real-time charts and summaries for monitoring requests by status and leave type.
- Enabled full request lifecycle management, from draft creation and submission to approval or rejection through secure role-based workflows.
